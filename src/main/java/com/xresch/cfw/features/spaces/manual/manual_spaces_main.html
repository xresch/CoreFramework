Spaces have been introduced to allow for multi-client capabilities and separation of projects. There are currently two types of spaces:

  • Root Space: A top level space that can contain other spaces, but itself cannot be moved below another space.
  • Space: A regular space that can be part of a Root Space or any other Space.
For Example, you could create a Root Space for every company and use regular Spaces to define projects.

Behavior

Spaces have the following characteristics, which will determine their behaviour:
  • Assigned Users / User Groups:  Allows defined Users or Groups if a user can see and select a space and work in the specified space. What they can do inside the space depends on the other permissions granted to the users by it's Roles and Group assignments.
  • Assigned Admins / Admin Groups:  Allows a user to change the space, add subspaces, add users and groups. There is no other rights this assignment grants. Any other admin privileges inside the space have to be granted by roles or groups.
  • Is Enabled: Enables or disables a space. If a space is disabled, the Space and anything in it will not show up in select dropdowns nor other places like autocomplete. Projects below it can still be enabled and will be visible if not explicitely
