This function has the purpose to load a CSV file form the file manager. This is especially useful for using a CSV file to lookup values. To autocomplete a file you have two possibilities:

  • Place your cursor after the opening brace "fileCSV(" and hit Ctrl+Space.
  • Place your cursor after "file:{searchTerm}", where searchTerm is a string to filter the list of files, and hit Ctrl+Space.

Let's say the file "people.csv" contains the following data:

"FIRSTNAME","LASTNAME","LOCATION","LIKES_TIRAMISU","VALUE","INDEX"
"Victoria","Fredriksson","Finias","false","55","1"
"Artemis","Eliasson","Pandaemonium","true","73","2"
"Venus","Johansson","Xibalba","true","69","0"
"Heracles","Jonsson","Dinas Affaraon","true","54","3"
"Bacchus","Viklund","Garden of Eden","true","91","4"
"Ares","Fransson","Aztlan","false","82","5"

The following query would read the file content globally as an array, and will check where the field FIRSTNAME is equals "Venus", and retrieves the values from the fields LASTNAME, LOCATION and LIKES_TIRAMISU:

| globals
	myArray = fileCSV({"id":197,"name":"people.csv"}, ";")
| source empty
| set
	lastname = arrayLookup( g(myArray), "FIRSTNAME", "Venus", "LASTNAME" )
	location = arrayLookup( g(myArray), "FIRSTNAME", "Venus", "LOCATION" )
	tiramisu = arrayLookup( g(myArray), "FIRSTNAME", "Venus", "LIKES_TIRAMISU" )
