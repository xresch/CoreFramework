THis function has the purpose to load a json file form the file manager. This is especially useful for using a json file to lookup values. To autocomplete a file you have two possibilities:

  • Place your cursor after the opening brace "fileJson(" and hit Ctrl+Space.
  • Place your cursor after "file:{searchTerm}", where searchTerm is a string to filter the list of files, and hit Ctrl+Space.

Let's say the file "myList.json" contains the following data:

{
	  "a": "apple"
	, "b": "berry"
	, "c": "cherry"
}

The following query would read the file content globally as an object, and will lookup the value for key "b", which is "berry":

| globals
	myList = fileJson({"id":429,"name":"myList.json"})
| source empty
| set
	lookup = objectLookup( g(myList), "b")

You can also do lookups of nested data. For example. the file "lookupCountries.json" contains the following data:

{
	  "CH": { "name": "Switzerland", "capital": "Bern" }
	, "UK": { "name": "United Kingdom", "capital": "London" }
	, "US": { "name": "United States", "capital": "Washington DC" }
}

The following query would read the name and capital of the country from the nested object:

| globals
	countries = fileJson({"id":461,"name":"lookupCountries.json"})
| record # create example records
	[country]
	["CH"]
	["US"]
	["UK"]
| set
	input = g(countries)
	name = objectLookup( g(countries), country).name
	capital = objectLookup( g(countries), country).capital
