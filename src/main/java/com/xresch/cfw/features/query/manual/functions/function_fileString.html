This function has the purpose to load the content of a file form the file manager. I have no clue why you would ever use this when you also have fileCSV() and fileJson(). If you ever need it, it is ready!

To autocomplete a file you have two possibilities:

  • Place your cursor after the opening brace "fileString(" and hit Ctrl+Space.
  • Place your cursor after "file:{searchTerm}", where searchTerm is a string to filter the list of files, and hit Ctrl+Space.

The following query reads the content of a file:

| globals
	myFileContent = fileString({"id": 123, "name":"myFile.txt"} )
| source empty
| set
	myString =  g(myFileContent)
