The objectLookup-function allows you to use an object as a list of key value pairs and lookup a value for keys. This function is case-sensitive.

The following query creates sample records and show some uses of the objectLookup-function:

| meta
	list = {
		  "A": "aaa"
		, "B": "bbb"
		, "C": "ccc"
		, "1": "111"
		, true: "trueTrue"
		, "[1,2,3]": "arrayArray"
		, "{\"x\":\"y\"}": "objectObject"
	}
| source empty records = 1
| set
	testA = objectLookup(m(list), "A")		# returns "aaa"
	testB = objectLookup(m(list), "B")		# returns "bbb"
	testD = objectLookup(m(list), "D")		# returns null
	testNull = objectLookup(m(list), null)	# returns null
	testOne = objectLookup(m(list), 1)		# returns "111"
	testBool = objectLookup(m(list), true)		# returns "trueTrue"
	testArray = objectLookup(m(list), [1, 2, 3])	# returns "arrayArray"
	testObject = objectLookup(m(list), {"x": "y"} )	# returns "objectObject"

This function is very useful in combination with the function fileJson() to load lookup values from the file manager. Let's say the file "myList.json" contains the following data:

{
	  "a": "apple"
	, "b": "berry"
	, "c": "cherry"
}

The following query would read the file content globally as an object, and will lookup the value for key "b", which is "berry":

| globals
	myList = fileJson({"id":429,"name":"myList.json"})
| source empty
| set
	lookup = objectLookup( g(myList), "b")

You can also do lookups of nested data. For example. the file "lookupCountries.json" contains the following data:

{
	  "CH": { "name": "Switzerland", "capital": "Bern" }
	, "UK": { "name": "United Kingdom", "capital": "London" }
	, "US": { "name": "United States", "capital": "Washington DC" }
}

The following query would read the name and capital of the country from the nested object:

| globals
	countries = fileJson({"id":461,"name":"lookupCountries.json"})
| record # create example records
	[country]
	["CH"]
	["US"]
	["UK"]
| set
	input = g(countries)
	name = objectLookup( g(countries), country).name
	capital = objectLookup( g(countries), country).capital
